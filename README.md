# Matjari — مستودع التوزيع (يُدار آلياً)

هذا المستودع **عام** ويحوي **نواتج موقّعة فقط**: تجديدات تراخيص الأجهزة وبيانات تحديثات البرنامج.
لا يحوي أي كود مصدري ولا أي مفتاح خاص — التوقيع يتم محلياً على جهاز المزوّد فقط.

- `licenses/<deviceId>.lic` — ملف ترخيص/تجديد موقّع لكل جهاز نشط.
- `updates/latest.json` — بيان التحديث الموقّع لأحدث إصدار من البرنامج.

تُنشَر المحتويات آلياً عبر لوحة المزوّد (`node cli.js publish-renewals` و`publish-release`).
